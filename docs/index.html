Overview

A horse sees the world through two eyes set on either side of its head: together they cover almost the full 360°, and their fields of view overlap in a narrow binocular region. HorseVision mimics this with a back-to-back dual-fisheye camera — a left eye and a right eye — and estimates 360° stereo panoramic depth for both eyes.

The two fisheye views are predicted by a shared Depth-Anything-V2 encoder, fused into equirectangular panoramas by geometric splatting, and refined by a lightweight ViT (MiniDA3). Self-supervision comes from the binocular overlap between the two lenses: each view is warped into the other using the predicted depth, and the photometric agreement yields a per-pixel confidence map.

At a glance

Input2 × fisheye RGB (518 × 518)
OutputPanoramic depth (518 × 1036), per-view fisheye depth, confidence maps
Peak GPU memory1.14 GB
End-to-end runtime3.9 s including model loading (RTX 4090)
ScenesIndoor (max 20 m, Structured3D / HM3D) · Outdoor (max 80 m, CARLA)

Quick start

git clone https://github.com/koshokai/HorseVision.git
cd HorseVision
git clone https://github.com/DepthAnything/Depth-Anything-V2.git
python download_models.py --scene outdoor
python test_single_conf.py

See the README for requirements, model zoo and configuration.
